## Descripción
Aplicación móvil con tres pestañas :
1. **Inicio:** muestra el nombre de la app y un contador con `useState` que se incrementa con un botón.
2. **Estudiantes:** lista de estudiantes en el estado, con un botón para agregar uno nuevo (sin mutar el arreglo).
3. **Estadísticas:** muestra la cantidad de estudiantes registrados.

`useEffect` se usa en Inicio (reacciona a los cambios del contador) y en Estadísticas (registra la hora de la última actualización de la lista).

## Tecnologías
- React Native + Expo
- TypeScript
- React Navigation (Bottom Tabs)

## Cómo ejecutar
```bash
npm install
npx expo start
```
